# Fast Paint

Windows 向けの Vulkan / Dear ImGui ベースのペイントアプリです。描画中からストロークをプレビューできます。

## ビルドと起動

Visual Studio Community 2026 の C++ 開発環境と Vulkan SDK を用意し、プロジェクトのルートで `build.bat` を実行します。Vulkan SDK は `VULKAN_SDK` 環境変数、または `C:\VulkanSDK` 以下から検出します。

## 操作

- 左のアイコン式サイドバーで色、筆、消しゴム、太さ（1〜256 px）を選択
- キャンバス上をドラッグして描画
- `Ctrl+N` で新しいキャンバス、`Ctrl+Z` で取り消し、`Ctrl+Y` でやり直し

描画中は時間・移動速度に応じたチェックポイントでストロークを更新し、既存の RDP 間引きと Catmull–Rom 補間を適用します。

## 構成

- `UI/Windows` — ウィンドウ、キャンバス、ツールバー、サイドバー
- `Core_Engine/Stroke_Engine` — ストロークの記録、補間、Undo / Redo
- `Core_Engine/Graphic_Engine` — ストローク描画処理
- `third_party` — Dear ImGui と GLFW

## ストロークエンジン

- **動的チェックポイントとサンプリング**: マウス/ペンの移動速度に応じたチェックポイント（60〜240 Hz）で入力点を取り込み、入力負荷の軽減とリアルタイムなプレビュー更新を両立
- **RDP（Ramer–Douglas–Peucker）間引き**: ストローク描画時に直線上にある不要な中間点をアルゴリズムで除去し、データ量と描画負荷を削減
- **Catmull–Rom スプライン補間**: 間引き後の点列に対して位置をCatmull–Rom曲線、太さを線形補間し、曲げ角度（カーブの急鋭度）に応じて分割数を動的に増やすことで滑らかな曲線を描画
- **$O(1)$ Undo / Redo**: 完了したストローク履歴（`completed_strokes_`）と取り消し用スタック（`redo_stack_`）の間で `std::move` を用いて高速に要素を移送

## 描画エンジン

- **CPU (SDF) レンダリング**: 距離関数（SDF）と AABB カリング、キャッシュ活用により、CPU 上で高速・高品質なアンチエイリアス描画を実現
- **Vulkan アクセラレーション**: ストローク頂点データを SSBO 用バッファ（`VulkanPoint`）へ高速変換し、GPU 描画へ引き渡し
- **可変太さ・テーパー対応**: 筆圧や速度変化に伴う始点・終点の太さ違い（テーパー形状）を幾何補正してスムーズに補間
